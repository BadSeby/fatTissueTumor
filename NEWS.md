# fatTissueTumor 0.1.0

* First public release.
* Added advanced preprocessing pipeline for gene expression data.
* Automatic data import from GEO, TCGA, and ArrayExpress.
* Co-expression analysis and GO/KEGG enrichment functions.
* Integrated visualization tools for quality control and enrichment results.
* Included thematic example datasets (breast, colon, ovary, co-culture).
